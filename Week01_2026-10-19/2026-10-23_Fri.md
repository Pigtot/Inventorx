## Problems and fixes
| Problem | Cause | Fix |
|---|---|---|
| A script crashes if no arm answers | `XArmAPI(ip)` throws an error when nothing is at that address | The scripts catch the error with `try/except` and print a clear message |
| A MacBook has no Ethernet port | | A USB-C to Ethernet adapter, set by hand to 192.168.1.100 |
| `set_position` can send the arm somewhere unexpected | If you leave out values, it fills them in from the last position you commanded, not from where the arm is now | Always give all six values, or use `relative=True` |

## Key idea
Before any code moves the arm, test it without moving. `01_hello_arm.py` only reads the arm's position, so it's a safe way to check the cable and the address. Every real move then uses the same four-step get-ready routine (clear errors, turn on the motors, pick a mode, set ready). Start slow, and keep someone's hand near the E-stop. Every command returns a code, and 0 means OK.
